# Story 1.2 — Fluxo Completo de Mensagens com IA

## User Story

**Como** nutricionista,  
**Quero** que minha assistente virtual responda automaticamente às mensagens dos pacientes no WhatsApp,  
**Para** atender fora do horário e reduzir carga de trabalho.

## Pré-requisito

✅ Story 1.1 concluída (WhatsApp conectado)

## Critérios de Aceitação

- [ ] **AC1** — Paciente envia mensagem → Evolution API recebe
- [ ] **AC2** — Evolution API dispara webhook para `http://nutriapp_api:3001/webhook/whatsapp`
- [ ] **AC3** — API valida header `x-internal-key` e processa evento `messages.upsert`
- [ ] **AC4** — n8n recebe evento, chama Claude AI com contexto da assistente configurada
- [ ] **AC5** — Claude AI gera resposta baseada na mensagem + configurações do assistente
- [ ] **AC6** — Resposta enviada de volta ao paciente via Evolution API
- [ ] **AC7** — Mensagens de outros bots ou do próprio número são ignoradas (não geram loop)
- [ ] **AC8** — Erros no fluxo são logados sem derrubar o webhook handler

## Dev Notes

### Fluxo de Dados

```
Paciente → WhatsApp → Evolution API → POST /webhook/whatsapp (API Fastify)
                                                    ↓
                                           n8n Webhook Trigger
                                                    ↓
                                         Claude AI (Anthropic API)
                                                    ↓
                                    POST /message/sendText/{instanceName}
                                                    ↓
                                         Paciente recebe resposta
```

### Configuração Evolution API

```
WEBHOOK_GLOBAL_URL=http://nutriapp_api:3001/webhook/whatsapp
WEBHOOK_GLOBAL_WEBHOOK_BY_EVENTS=false  # CRÍTICO: não adicionar sufixo do evento
WEBHOOK_GLOBAL_ENABLED=true
WEBHOOK_EVENTS_MESSAGES_UPSERT=true
```

### n8n Workflow

- **Workflow:** "WhatsApp Message Handler"
- **Trigger:** Webhook em `POST /webhook/whatsapp` (via n8n)
  - Atenção: verificar se n8n usa URL própria ou redireciona da API Fastify
- **HTTP Request node:** URL deve ser `http://nutriapp_api:3001/...` (container name, não localhost)
- **Header:** `x-internal-key: {INTERNAL_API_KEY}`

### Arquivo webhook handler

- `apps/api/src/routes/webhook.routes.ts` (ou similar)
- Evento relevante: `messages.upsert` com `key.fromMe === false`

### Anti-loop

Ignorar mensagens onde:
- `key.fromMe === true` (mensagem do próprio número)
- `message.protocolMessage` existe (mensagem de sistema)
- `pushName` é null/undefined (bot)
