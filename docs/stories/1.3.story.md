## Dev Notes

### Endpoints Existentes

```
GET  /api/assistants              → retorna configurações do assistente
POST /api/assistants              → salva nome + greeting_message
POST /api/assistants/upload-pdf  → upload do arquivo PDF
DELETE /api/assistants/pdf        → remove o PDF
```

### Integração PDF + Claude AI (n8n)

O n8n deve:
1. Fazer `GET /api/assistants` para obter caminho/conteúdo do PDF
2. Ler o PDF e extrair texto
3. Incluir o texto como contexto no prompt do Claude:
   ```
   Você é {assistant.name}, assistente virtual do consultório.
   
   Sua mensagem de boas-vindas padrão: {assistant.greeting_message}
   
   Base de conhecimento do consultório:
   {pdf_content}
   
   Responda a seguinte mensagem do paciente: {message}
   ```

### UI — Arquivo relevante

- `apps/dashboard/src/app/(dashboard)/configuracoes/page.tsx`
- Componente `TabAssistant` (já implementado parcialmente)

### Lógica de Primeiro Contato

- Verificar se já existe histórico de conversa com aquele número
- Se não existe: enviar `greeting_message` primeiro, depois processar mensagem
- Tabela `conversations` ou `message_history` necessária
