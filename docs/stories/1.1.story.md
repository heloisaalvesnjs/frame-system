# Story 1.1 — Conexão WhatsApp via Pairing Code

## User Story

**Como** nutricionista,  
**Quero** conectar meu WhatsApp ao sistema usando um código de pareamento,  
**Para** ativar a assistente virtual no meu número sem precisar escanear QR Code.

## Status

**Atual:** 🔄 In Progress  
**Blocker:** Testando pairing code após fix do campo `number` (era `phoneNumber`)

## Critérios de Aceitação

- [ ] **AC1** — Nutricionista digita número no formato `5511999999999` e clica "Conectar"
- [ ] **AC2** — Sistema cria instância na Evolution API e aguarda ~10s
- [ ] **AC3** — Código de 8 caracteres aparece em destaque na tela
- [ ] **AC4** — Nutricionista insere código no WhatsApp → Dispositivos → Vincular com número
- [ ] **AC5** — Status muda para "Conectado" automaticamente (polling 3s)

- [ ] **AC7** — Botão "Desconectar" visível quando conectado
- [ ] **AC8** — Se erro, mensagem descritiva é exibida (não genérica)

## Dev Notes

### Arquitetura

- **Evolution API v2** (`https://nutriapp-evolution2.uhep36.easypanel.host/`)
  - Instâncias criadas via `POST /instance/create` com `{ instanceName, qrcode: true, integration: 'WHATSAPP-BAILEYS' }`
  - Pairing code via `POST /instance/pairingCode/{instanceName}` com body `{ number: "55..." }`
  - Status via `GET /instance/fetchInstances?instanceName={name}` → `state: 'open'` = conectado

- **API Fastify** (`apps/api/src/routes/whatsapp.routes.ts`)
  - Tabela `whatsapp_connections` com campos: `nutritionist_id`, `instance_name`, `status`, `phone_number`, `qr_code`, `connected_at`
  
- **Dashboard Next.js** (`apps/dashboard/src/app/(dashboard)/configuracoes/page.tsx`)
  - Componente `TabWhatsApp` com estados: `connecting`, `pairingCode`, `pairingPhone`, `mode`
  - Polling de status via `useQuery` com `refetchInterval: 5000`
